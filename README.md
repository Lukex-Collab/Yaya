# Yaya 3D 世界

灵伴世界（lingpal-world）3D 世界开发代码，独立存放于本仓库。

## 示意图

世界布局与探索规划参考图（2026-08-02 生成）：1 个中心枢纽 + 6 个外围区域的有机开放世界，区域间以路径网络连接。

## 目录

- `cocos-project/` — Cocos Creator 3.8.5 3D 世界项目（TypeScript 脚本、3D 模型、世界配置）
- `wechatgame/` — 微信小游戏原型（原生 JavaScript 实现）
- `images/` — 世界布局与探索规划参考示意图
