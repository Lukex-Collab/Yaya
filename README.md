# 瓦奇 Waki

瓦奇 Waki（原 Yaya / 牙牙 / 芽芽）是结合线上互动与实体设备探索的 AI 陪伴项目。本仓库保存瓦奇线上原型及硬件方案资料。

## 线上原型

`waki-online/` 包含聊天界面、养成、手账、瓦奇眼睛拍摄与画面分析，以及设备状态、联系人验证、位置路线和 SOS 回执演示。

需要 Node.js，无需安装依赖。在仓库根目录执行：

```powershell
cd waki-online
node server.js
```

打开 <http://127.0.0.1:4173>。

在 `waki-online/` 目录运行自动检查：

```powershell
npm test
```

详细运行说明与素材限制见 [原型说明](waki-online/README.md)。

## 硬件方向

当前方案围绕 ESP32-S3、麦克风与扬声器、摄像头、GNSS/GPS 定位、4G 联网及便携供电展开，目标场景包括语音陪伴、主动拍照问答和设备位置上报。

- [硬件 V0.1 规格与采购底稿](docs/waki/hardware-v0.1.md)：候选器件、供电要求、采购检查和分阶段验收。
- [资料索引与验证状态](docs/waki/README.md)：资料来源、同步范围及待补齐的验证证据。

硬件底稿日期为 2026-10-09，属于原型验证方案，不是最终 BOM、量产规格或已完成的实物测试报告。本次资料不包含新增固件、PCB 或接线图。

## 当前边界

- 设备状态、联系人验证、位置路线和 SOS 回执均为模拟，不代表真实设备接入、真实通知送达或紧急服务联动。
- 静态服务器不提供真实 AI 聊天、视觉识别或语音后端；本地画面分析不等于语义识物。
- 3DGS 福尔摩斯房间素材已放入静态发布目录；自动检查不能代替浏览器中的渲染验证或硬件联调。
- 户外联网、定位、语音与摄像头联合运行、峰值功耗、温升和续航仍需验证。
- 设备位置不等于人的位置；设备与人分离时不能据此判断人的位置。

## Netlify 部署

从 GitHub 导入本仓库时，Base directory 和 Build command 均留空，Publish directory 填 `waki-online/app`。无需构建；访问部署后的站点根路径即可打开原型。

发布目录里的福尔摩斯房间扫描、图片与视频会成为公开可访问的静态文件。Netlify 不运行本地 `server.js`，因此 `/api/*` 的聊天、识图等服务端接口不会由这次静态部署提供。

历史资源文件名及旧本地存储迁移逻辑保留，以兼容已有数据。此次说明调整不删除仓库中其他已有代码或素材。

## 数据与安全

密钥、令牌、日志、调试录音、私人日记和真实联系人数据不得提交。真实服务接入需另行实现设备身份、传输保护及通知送达校验，不应将演示原型直接用于紧急求助。
