# 灵伴世界 · 微信小游戏可玩原型（wechatgame）

> **定位**：程序化占位美术的**探索手感 / 世界拓扑验证原型**。
> 最终治愈系美术走 **Cocos Creator**（见 `../cocos-project` 与四份规划文档）。
> 本目录**不含**美术资产、音频、扫码/NFC 绑定、预制宠物内容、语音——这些属于"功能后叠"。

---

## 它是什么

- **零外部依赖**的原生 WebGL 微信小游戏工程（`game.js + game.json + project.config.json` + `wx.*` API）。
- 程序化生成 Low-Poly 圆形岛：中心 **HUB 灵屿村** + 6 个外围扇区 + 海岸水面，顶点色 + 半 Lambert 光照 + 距离雾。
- 已实现的探索闭环：
  - 2.5D 等距正交相机，平滑跟随 + 双指捏合 / 滚轮缩放 + 世界边界钳制
  - 左下虚拟摇杆移动，双击摇杆切跑步
  - 点击空地 = 等距网格 **A\* 寻路**（含滑墙、对角阻挡检查、路径简化）；点击建筑/树/岩壁 = 自动走到它旁边
  - 宠物跟随 + 随机嗅探的轻量行为
  - 进入不同区域时**色调 / 雾 / 雾距**平滑过渡
  - 右上圆形**小地图** + 已探索区域 + 探索雾
  - 帧率采样 → HIGH / MID / LOW 三档（LOW 关水面）

## 运行（手机真机）

1. 安装并登录 **微信开发者工具**。
2. 「导入项目」→ 目录选**本 `wechatgame` 文件夹** → AppID 填你的小游戏 AppID；没有可先选「测试号」或留空（仅模拟器可跑，预览扫码需真实小游戏 AppID）。
3. 编译运行 → 模拟器应看到 3D 岛 + 左下摇杆 + 右上小地图。
   - 控制台应打印：`[LingPal] world built: opaque tris=6868 water tris=1152`
   - 性能档变化时打印：`[perf] HIGH/MID/LOW fps=xx`
4. 真机：点工具栏「**预览**」生成二维码 → 手机**微信扫码** → 在微信内打开即可玩。

## 操作

| 操作 | 效果 |
|---|---|
| 左下摇杆拖动 | 八向移动（屏幕方向已换算为等距世界方向） |
| 双击摇杆 | 切换跑步 |
| 点击空地 | A\* 寻路走过去 |

| 双指捏合 / 鼠标滚轮 | 缩放相机 |

## 已知限制（诚实清单）

- **占位美术**：几何 + 顶点色，非最终治愈系美术；最终美术走 Cocos + glTF/Spine。
- **无音频 / 无绑定 / 无预制内容 / 无语音**：属功能后叠，不在本切片。
- **渲染层需真机实测**：shader 编译、触摸手感、UI 像素布局、真机帧率，本开发环境无 GPU 与 `wx` 运行时，**无法代验**，以上控制台日志为对照基线。
- 程序化世界为单 mesh 一次性生成，**未做 chunk 流式加载**（原型世界小，无需；正式工程按 `ChunkManager` 做）。
