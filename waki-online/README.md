# Waki Online

瓦奇线上产品原型。这个副本不包含原项目的密钥、日志、调试录音或用户日记。

## 启动

```powershell
node server.js
```

打开 `http://127.0.0.1:4173`。

运行核心流程检查：

```powershell
npm test
```

当前版本包含品牌迁移、旧本地数据兼容、设备状态模拟、联系人验证、SOS 事件回执、位置路线模拟、瓦奇眼睛拍摄与视觉回应，以及养成/手账子页切换修复。

线上守护演示路径：打开“守护” → 添加并测试联系人 → 打开“位置守护” → 点击“模拟深夜偏离” → 查看发送中与模拟送达记录。

瓦奇眼睛演示路径：打开“瓦奇眼睛” → 拍摄、选择照片或使用内置演示画面 → 查看 AI / 本地画面分析 → 带回聊天。页面会明确区分手机/电脑输入、内置演示画面与未来真实硬件。

## 仓库集成与限制

- 本目录是独立原型，不替换灵伴世界的 `web2d/`、`web/` 或根目录服务。启动和测试仅使用 Node.js 内置模块，无需 `npm install`。
- 背景图、宠物 GLB 及三段视频通过服务器的明确路径映射复用仓库已有文件，不重复提交二进制素材。视频采用仓库版本，与本地旧原型视频并非逐字节相同；未覆盖原有视频。
- 本地副本没有 `room.ply`、`violin.ply` 和 `holmes-room.jpg`，本次也没有新增这些素材。相应 3DGS 房间演示不完整；通过烟雾测试不代表这些视觉场景已验证。
- 静态服务器不实现 `/api/chat`、`/api/vision` 或语音后端。真实 AI 对话与视觉识别需要另行接入服务，前端本地画面分析不是语义识物能力。
- 联系人验证、定位路线、SOS 送达和设备状态属于模拟。不能将此页面作为真实紧急求助系统。
- 原有 `yaya` 资源名和旧存储迁移逻辑保留，以兼容历史数据；未导入任何用户的实际浏览器数据。
- 外部 CDN 脚本需要网络；本次自动检查不涵盖完整浏览器、摄像头权限、外部 CDN 或硬件联调。

硬件背景见 [资料索引](../docs/waki/README.md) 和 [V0.1 底稿](../docs/waki/hardware-v0.1.md)。
